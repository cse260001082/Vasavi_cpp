# OOP syntax practice

Vasavi, work through these exercises in order, one file at a time. Explain what you plan to write before starting.

- Questions 1–8 are fill-in-the-blanks. Replace each `___` with the missing C++ syntax. A blank may need a symbol, a word, or an expression.
- Questions 9–15 contain only comments. Write the complete program yourself, including headers and `main()`.
- Each `.cpp` file is a separate program. Compile and run only the file you are working on; do not compile all these files together.
- Predict the output before running. Use the checks in each file to review your work.
- The unfinished fill-in-the-blanks files are expected to have compilation errors until you complete them. No answer key is included.

Refer to [the notes](../notes.md) when needed. If stuck, ask for one hint and try again.
