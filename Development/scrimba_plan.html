Week 1

From pages to programs

  1. Session 01

    Build a Birthday Website

    HTML and CSS Fundamentals

    If you need a refresher first, revisit the relevant part of Intro to HTML or Intro to CSS in Scrimba.

    What you will learn
    How to group and center content, style photos and text, and change an element when the pointer hovers over it.
    What you’ll have
    A birthday page with a styled greeting and at least one surprise image that appears on hover.
  2. Session 02

    Solo Project: Hometown Homepage

    HTML and CSS Fundamentals

    What you will learn
    How to turn a design brief into sections and arrange images and text with spacing and Flexbox.
    What you’ll have
    Your own hometown page with an opening section, local highlights and a guide card that match the Scrimba brief.
  3. Session 03

    Build a Counter App

    JavaScript Fundamentals

    What you will learn
    How a variable remembers the count and how a click runs a function that updates the text on the page.
    What you’ll have
    A counter app that increases on a click, records the current count, and resets the counter for the next entry.
  4. Session 04

    Solo Project: Basketball Scoreboard

    JavaScript Fundamentals · Then Git and GitHub basics

    What you will learn
    How to track two scores independently, connect buttons to the right score, and save a version of your work with Git.
    What you’ll have
    A scoreboard with working +1, +2 and +3 buttons for both teams, plus a Git commit that describes what you built.
  5. Session 05

    Build a Blackjack Game · Part 1

    JavaScript Fundamentals

    Start the section and go through the lesson where a loop displays the cards on the page.

    What you will learn
    How conditions choose a game message, how an array holds the cards, and how a loop displays them.
    What you’ll have
    A first version that shows the cards, their total and a message when you start the game or add a card.
  6. Session 06

    Build a Blackjack Game · Part 2

    JavaScript Fundamentals

    Resume after the card display lesson and finish the section.

    What you will learn
    How functions return random card values, how to combine conditions, and how an object groups player details.
    What you’ll have
    A playable Blackjack game that deals random cards and stops drawing after a win or a bust.
  7. Session 07

    Solo Project: Password Generator

    JavaScript Fundamentals

    What you will learn
    How to pick a random item from a list, repeat that selection in a loop, and combine the characters into a string.
    What you’ll have
    A practice app that displays two generated passwords of the brief’s required length when you click the button.

Week 2

Build more and refine your work

  1. Session 08

    Build a Chrome Extension · Part 1

    JavaScript Fundamentals

    Go through the first time the course loads the extension into Chrome. Save browser storage for part 2.

    What you will learn
    How to read a text field, handle clicks, show a list of links, and describe an extension to Chrome with a manifest file.
    What you’ll have
    A first extension running in desktop Chrome. Its popup adds a link you type to the visible list.
  2. Session 09

    Build a Chrome Extension · Part 2

    JavaScript Fundamentals

    Resume at browser storage and finish the section.

    What you will learn
    How to keep data with browser storage, pass different lists to a display function, and get the current tab’s address.
    What you’ll have
    A working extension that saves typed links or the current tab, remembers them when reopened, and can clear the list.
  3. Session 10

    Solo Project: Unit converter

    JavaScript Fundamentals

    What you will learn
    How to read input as a number, apply conversion formulas and format the results to a fixed number of decimal places.
    What you’ll have
    A converter that shows length, volume and mass in both directions. You can check its results with a few known inputs.
  4. Session 11

    Command Line Fundamentals

    Tools of the Trade · Then Essential Git and GitHub Skills

    Save Command Line Power Tools for later.

    What you will learn
    How to navigate folders from the terminal and use Git to review, stage, commit and push a change.
    What you’ll have
    A practice repo where you can find your files in the terminal and see a commit you pushed on GitHub.
  5. Session 12

    Build an NFT Site · Part 1

    Essential CSS

    Go through the lesson that styles the footer.

    What you will learn
    How to use meaningful HTML sections, contain the width of content and use Flexbox to arrange images.
    What you’ll have
    A first version of the Scrimba page with a header, styled content sections and a footer.
  6. Session 13

    Build an NFT Site · Part 2

    Essential CSS

    Resume after the footer and finish the section.

    What you will learn
    Why one CSS rule wins over another, how to share styles across buttons, and how to handle items that need to wrap.
    What you’ll have
    A finished page with reusable button styles and one small visual change you can explain, such as a different hover state.
  7. Session 14

    Catch up, rebuild and explain

    Review your Scrimba projects

    What you will learn
    Which part of a feature you can recreate from memory and where you still need a reference.
    What you’ll have
    Any unfinished work caught up, plus a small feature you can rebuild from a blank file and explain in your own words.

    If you finish early, Build a Portfolio in Essential CSS is an optional next project.
