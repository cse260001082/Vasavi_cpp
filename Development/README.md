# Development

Web projects, built with plain HTML, CSS and JavaScript.

## Dice Roll

Your project for the Programming Club (Software Division) induction.

```
Dice Roll/
  index.html, style.css, script.js   the project itself
  images/                            dice1.svg to dice6.svg
  prep/
    Induction_Problem_Statements_Software_Division.pdf   what the club asks for
    practice.md        10 tasks, from HTML to JavaScript, building up to the project
    practice/          one folder per task, with a check panel on each page
    study_guide.html   interview revision: every line explained, a click trace, likely questions
```

Suggested order:

1. Do the practice tasks 1 to 10 in `prep/practice.md`. `prep/practice/README.md` explains the check panel.
2. Revise with `prep/study_guide.html` until you can explain every line of the project.
3. Do the final challenge at the end of `practice.md`: rebuild the project from three empty files.

## Web Guide

`Web Guide/html_css_guide.html` teaches how the web works, then HTML and CSS, with demos you can click and quick checks after each section. Double-click it to open it in Chrome.

It is being built one part at a time:

1. How the web works: client and server, URLs, DNS, HTTP, HTTPS, how the browser draws a page, and opening your page three ways. Ready.
2. HTML: tags, the page skeleton, links and paths, images, lists, tables, forms, semantic layout, id and class, and the Elements panel. Live editors and 8 challenges. Ready.
3. CSS. The first half is ready: adding CSS, rules, selectors, classes, combinators, inheritance, the cascade and specificity, pseudo-classes, colours, units, the box model and margins, with 6 challenges. The second half, layout and motion, comes next.
4. Wrap-up: cheat sheets and glossary. Coming next.
