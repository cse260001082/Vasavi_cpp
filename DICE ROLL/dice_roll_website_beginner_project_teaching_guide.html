🧠 How This Works: The 5 Core JS & DOM Concepts

Tip: Click "Inspect 3×3 Grid (0–8)" at the top to see how Concept #2 works live!
1

Unbiased Random Number

Math.random() gives a decimal from 0 to 0.999.... Multiplying by 6 and flooring gives 0..5, and adding 1 gives an equal chance for 1..6. 

Math.floor(Math.random() * 6) + 1;
2

3×3 Grid Pip Lookup Map

Each die has 9 cells numbered 0 to 8. A dictionary object maps each dice number (1–6) to the exact cell positions that should show a dot: 

1: [4],       // Center dot
2: [0, 8],    // Top-L, Bot-R
6: [0,2,3,5,6,8]
3

DOM Class Manipulation

Instead of deleting HTML on every roll, we toggle CSS classes like .rolling for the shake animation and .active to show or hide pips. 

dieEl.classList.add('rolling');
pipEl.classList.toggle('active', isOn);
4

Timers for Roll Animation

setInterval rapidly cycles random faces every 75ms while shaking, and setTimeout stops the roll after 550ms to reveal the real result. 

const timer = setInterval(cycleFace, 75);
setTimeout(() => clearInterval(timer), 550);
5

Creating DOM Elements

After each roll, we store the result in an array and dynamically create a new <li> item for the Roll History list using document.createElement('li'). 

const li = document.createElement('li');
historyList.prepend(li);
